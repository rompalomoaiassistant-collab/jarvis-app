# Jarvis Privacy Policy

Jarvis is a private, single-user personal assistant used only by Rom Palomo.

## What data Jarvis accesses

Jarvis accesses only Rom's own Google Calendar (rom.palomo.ai.assistant@gmail.com), to read his schedule and to add or change events he approves.

## How the data is used

Calendar data is used only to plan and manage Rom's own schedule. It is processed on Rom's own computer.

## Sharing

Jarvis does not sell, share, transfer, or disclose any Google user data to any third party. No data is used for advertising.

## Storage and deletion

Data stays on Rom's own computer. Access can be revoked at any time from the Google Account permissions page.
